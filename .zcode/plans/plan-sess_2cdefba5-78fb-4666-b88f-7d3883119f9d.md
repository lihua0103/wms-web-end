## 设计方向
建立一套“Global Warehouse Control Tower / 全球仓网控制塔”标准：平台特色不靠装饰性渐变，而靠三个稳定识别点：全球货流路径、仓网节点状态、AI 决策入口。整体维持企业级 B 端产品的高密度、强对比、低噪音视觉。

## 登录页改造
文件：`src/views/login/index.vue`

1. 保留现有登录逻辑、校验、记住账号、主题切换、语言切换和路由跳转，不改认证契约。
2. 重排品牌区为“控制塔”信息结构：
   - 顶部使用平台 Logo、中文名和英文副标识。
   - 中部使用明确的价值标题，突出“仓网感知 / AI 决策 / 全球履约”三项能力。
   - 用轻量的网格、节点、航线和状态标记替代目前偏宣传海报式的光晕与大装饰。
   - 将能力卡改为更紧凑的运营指标条，降低视觉噪音，提升首屏信息层级。
3. 重排登录区为“工作入口”而非营销卡：
   - 使用窄而清晰的表单列，强化账号、密码、记住我、登录主按钮的层级。
   - 增加登录区的环境/授权状态信息，但继续通过现有 i18n 文案提供。
   - 保留协议、忘记密码、演示账号等现有行为和文案 key，避免业务回归。
4. 响应式：桌面保留品牌区，平板收窄品牌内容，移动端隐藏品牌区并让表单保持稳定宽度。
5. 所有颜色与交互态优先使用 `--el-color-primary`、`--pure-theme-*` 和现有 Element Plus 变量；不新增硬编码主色体系。
6. 清理未使用的旧登录 CSS 依赖，仅在 `index.vue` 内完成样式闭环，避免影响其他页面。

## 侧边栏改造
文件：`src/layout/components/lay-sidebar/components/SidebarLogo.vue`、`src/style/sidebar.scss`、`src/style/wms-theme.scss`

1. Logo 区改成“品牌 + 当前运营上下文”结构：
   - 展开态显示品牌名、WMS 英文标识和简短的控制塔副标识。
   - 折叠态保持纯图标和可用 tooltip，不改变路由行为。
2. 菜单层级统一为控制塔导航规范：
   - 顶层模块使用更稳定的 40px 节奏、清晰的图标列和有限的激活色块。
   - 子菜单通过缩进、背景层级和左侧状态线表达，不使用过度圆角或大面积胶囊。
   - 激活态只保留一个强信号：主色背景 + 白字；悬停态使用主题变量的低对比填充。
   - 统一弹出菜单、折叠态、移动端的边界与阴影，保证交互连续性。
3. 侧栏底部增加轻量“AI Agent 在线/本地预览”状态入口视觉，但不新造业务功能；如现有结构不适合挂载，则只通过 Logo/菜单区留出品牌识别位，不改权限和路由。
4. 对深色默认主题重点打磨，同时保证浅色、深色和主题切换仍由 pure-admin 变量接管。
5. 菜单图标继续走 `src/components/ReIcon/src/offlineIcon.ts` 离线注册机制；如新增图标，只登记必要图标，不引入网络依赖。

## 国际化与规范
1. 新增或调整的可见文案同时补齐 `src/locales/zh-CN.yaml` 和 `src/locales/en.yaml`，页面不写死业务文案。
2. 颜色遵循已有记忆约束，主色走 `--el-color-primary`，侧栏走 `--pure-theme-*`。
3. 避免再引入未经验证的装饰性渐变、过大的圆角卡片和与仓储业务无关的插画。

## 验证
1. 运行 `pnpm typecheck`。
2. 运行 `pnpm build`。
3. 启动 Vite 开发服务器，使用浏览器自动化分别验证登录页桌面/移动布局、登录交互、侧栏展开/折叠、激活态、子菜单和主题切换。
4. 检查浏览器截图，重点确认文字不溢出、表单不偏移、菜单层级和激活态清晰。
