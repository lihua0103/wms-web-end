# 智联仓储 WMS · UI 设计规范

> 设计语言：**深海藏青 × 远航青 × 国际橙** —— AI 智能国际物仓平台，数据密集、品牌克制。
> 实现层：`src/style/wms-theme.scss`（全局皮肤，自动作用于所有页面）。
> **颜色一律走 pure-admin 主题变量**（见第九节），禁止硬编码色值；文案一律走 i18n 语言包。

## 一、设计原则

1. **标准企业范式**：侧栏 + 顶栏 + 多标签 + 内容区，参考 Ant Design Pro / 阿里云控制台，禁止非标装饰（副标题、灯条、分区标签等）；
2. **一屏两卡**：每个列表页 = 搜索卡片 + 表格卡片，中性冷灰背景上浮起；
3. **状态即语义**：业务状态一律"胶囊标签 + 语义圆点"，颜色由字典控制；
4. **数字可读**：数量/单号全局 tabular-nums；
5. **品牌只靠配色**：藏青底 + 远航青主色 + 国际橙点缀，内容区用色鲜活（KPI 彩盒、青橙图表）。

## 三、布局框架与尺寸

| 部位 | 尺寸 |
|---|---|
| 侧栏展开宽 | 220px（vertical/mix）；右侧圆角 8px |
| 侧栏折叠宽 | 54px |
| Logo 区高 | 58px（30px 图标 + 单行系统名，发丝分隔线；无副标题/状态行） |
| 顶栏高 | 48px（面包屑在左，右侧依次：智能体、搜索、语言、全屏、通知、用户、设置） |
| 菜单项 | 顶层 40px / 子级 36px，行距 2px，左右留白 8px，圆角 6px |
| 内容区间距 | 24px |

### 侧边栏交互模型（三态三信号，互不重叠）

- **悬停**：`rgba(255,255,255,.07)` 浮层 + 文字/图标提亮白 + 顶层项**右移 2px**（可按反馈；子级与折叠态不位移，避免抖动）；`focus-visible` 与悬停同态，键盘可达；
- **展开中/含选中的父级**：仅文字点亮白 + 图标提亮 + 箭头转信号青，**不加底色**；
- **选中项**：主色实底 + 白字 + 顶部 1px 内高光 + 主色轻投影，左缘 **3px × 18px 信号青指示条**（整栏唯一的强信号）；子级选中同款（圆角 4px）；
- **折叠态**：含选中子项的父级 → 图标转信号青 + 左缘指示条；弹出层为画布深层浮层 + 8px 圆角 + 深投影，选中主色实底；
- **图标着色**：静息 `rgba(203,222,241,.60)` → 悬停/选中 `#fff`（独立于文字色）；
- **字重**：顶层 500 → 选中 600；子级 400 → 选中 500；
- **子菜单**：画布深层整条圆角面板（缩进表达层级，行间无条纹）；
- **底部折叠按钮**：画布同底 + 顶部发丝线，图标次级文字色 → 悬停白；侧缘折叠把手为画布深层底 + 信号青箭头；
- **禁止**：副标题、状态行、下拉切换器、分区标签、顶部渐变条、发光灯条、引导线。

### 登录页「数字孪生仓」

- **整页一块藏青画布**（`--wms-navy → --wms-navy-deep` 165° 渐变，主色仅 4–8% 染色）+ 左上主色径向光晕 + 点阵网格（向下渐隐）。右侧不是硬切分栏，而是一张 **内嵌圆角「表单纸」**（`--el-bg-color`，四周 16px 留边，圆角 20px，1px 发丝描边 + 长投影），宽 `clamp(440px, 34vw, 560px)`；
- **画布内容**：Logo+系统名 → 信号青 eyebrow → 两行大标题（第二行整行信号青，非渐变文字）→ 一段副文 → 四项能力（发丝线胶囊）→ **签名视觉「等轴测数字孪生仓」** → 法律链接 + 版权。宽屏（>1800px）文案与场景左右并置、垂直居中；≤1800px 上下堆叠、靠左成一条内容柱；
- **签名视觉**：2:1 等轴测 SVG，几何在 setup 期一次性算好（`src/views/login/index.vue` 顶部常量）。三排线框货架（前脸 26% 白、背面 9% 白）、已占用货位为信号青立方体（顶/左/右三面由 `color-mix` 派生明暗），约 16% 货位「呼吸」表示作业中；两台 AGV 沿巷道 `animateMotion` 往返；地面网格向后渐隐 + 信号青光晕。其上悬浮三张玻璃质感实时作业卡片（`login.live.*`），位置用百分比锚定在 `.scene-frame`（该外框用 `cqh` 反推宽度，与 SVG 绘制区严格重合）；
- **表单纸**：右上角语言切换 + 明暗切换；「欢迎回来」+ 一句副文 → 账号/密码（label 在上，控件 46px，圆角 8px，聚焦为主色描边 + light-9 外圈）→ 记住我 / 忘记密码 → 主按钮（46px，箭头悬停右移 3px）→ 协议勾选 → 演示账号（虚线胶囊，整条可点「一键填入」）→ 安全提示；
- **响应式**：断点一律嵌套写在各自选择器内部（顶层 `@media` 会被后声明的基础规则覆盖）。`≤1800px` 堆叠；`≤1280px` 缩小画布内边距与标题；`≤1080px` 隐藏浮动卡片；`height ≤ 640px` 隐藏场景；`≤900px` 隐藏画布、表单纸铺满并显示 Logo+系统名；
- **动效**：货位呼吸 3.6s、AGV 13s/17s、卡片浮动 6s、状态点脉冲 2.4s；`prefers-reduced-motion` 全部关闭；
- 配色全部跟随主题变量：画布用 `--wms-navy*` + `--wms-signal` + 主色轻染，表单纸用 `--el-*`，暗色/任意主题色可用；文案全部走 `login.*` 国际化键。

| 组件 | 规范 |
|---|---|
| 卡片/搜索区 | 圆角 8px、边框 `#E8ECF2`、双层轻阴影 |
| 主按钮 | 品牌青渐变（135deg 主色→light-3）+ 投影，active 下沉 |
| 次按钮 | 描边 `#D6DDE8`，hover 青字淡青底 |
| 输入/选择器 | 圆角 6px、focus 主色 1.5px |

| 分页 | 激活页主色渐变胶囊 |
| 状态标签 | 胶囊（999px）+ 语义圆点，颜色走 `constants/wms.ts` |

| 描述列表 | 标签底 `#F5F7FA` 600 字重 |
| KPI 卡 | `wms-kpi-card`：数值 26px/700、图标底座 42px 渐变四色、hover 上浮 2px |

## 五、表格列宽规则（强制）

- 非固定列一律 `minWidth`（基准：日期 140、单号 130、名称 120、编码/状态 100、数量 80），**禁止 `width`**；仅固定操作列可用 `width`；
- 超宽由 `show-overflow-tooltip` 兜底。

## 六、约束

1. 页面禁止写死状态颜色（走 `constants/wms.ts`）、禁止自建卡片阴影/圆角、禁止硬编码品牌色（用 `var(--el-color-primary*)` / `var(--pure-theme-*)`）；
2. 禁止修改 `wms-theme.scss` 设计令牌适配单页需求；
3. 页面文案禁止硬编码，一律 `$t()` 走 `src/locales/*.yaml`（zh/en 两棵 key 树一致）；
4. KPI 卡用 `wms-kpi-card`；图标统一 `~icons/ep/xxx`（新图标在 `offlineIcon.ts` 登记）；
5. 系统名/品牌文案：`platform-config.json` 的 `Title` 配 i18n key（当前 `app.title`），渲染处经 `transformI18n` 翻译。

## 七、暗色模式

暗色模式（`html.dark`）保持 pure-admin 原生暗色体系；侧栏/品牌区配色经 `--pure-theme-*` 变量自动适配。

## 八、主题色机制（必须遵守）

| 场景 | 使用的变量 |
|---|---|
| 按钮、链接、分页、输入框 focus、侧栏选中胶囊 | `--el-color-primary` + `light-3/5/7/8/9`、`dark-2`（设置面板切换联动） |
| 侧栏底色、Logo 区、菜单文字、悬停底色 | `--pure-theme-menu-bg`、`--pure-theme-sidebar-logo`、`--pure-theme-menu-text`、`--pure-theme-menu-hover`、`--pure-theme-sub-menu-*` |
| 折叠指示条、父级箭头高亮 | `--pure-theme-menu-active-before` |
| 半透明派生色 | `color-mix(in srgb, var(--…) N%, transparent)`，不写死 rgba |

默认主题（default）为设置面板色板第 2 个色块，色值即品牌主色 `#0E7490`。

## 九、智能体（WMS 智能体）

参考 Dify / LobeChat 范式，实现在 `src/layout/components/lay-ai/index.vue`：顶栏品牌渐变胶囊入口 + 在线状态点；460px 侧滑抽屉（技能卡、流式对话、工具轨迹）；`AiEndpoint` 为空时自动降级本地预览引擎，后端就绪后在 `send()` 接入会话 API，界面无需改动。
