# 智联仓储 WMS · UI 设计规范

> 设计语言：**深航蓝 × 仓储橙** —— 为仓储物流场景定制的专属视觉体系。
> 实现层：`src/style/wms-theme.scss`（全局皮肤，自动作用于所有页面）+ 页面级组件类。
> 新页面**无需额外样式代码**即自动继承本规范；如需定制，只用本文档定义的类与变量。

## 一、设计原则

1. **一屏两卡**：每个列表页 = 搜索卡片 + 表格卡片，圆角 12px、冷灰蓝背景上浮起；
2. **状态即语义**：所有业务状态用"胶囊标签 + 语义圆点"呈现，一眼读出单据状态；
3. **数字可读**：所有数量/单号使用等宽数字（tabular-nums），对齐不跳动；
4. **深蓝导航、浅色工作区**：侧边栏承载品牌（夜航蓝渐变），内容区保持冷静克制。

## 二、色彩系统

| 令牌 | 值 | 用途 |
|---|---|---|
| 品牌主色 Primary | `#2563EB` | 主按钮、激活态、链接、选中 |
| 主色浅阶 | light-3/5/7/8/9 自动派生 | hover、淡底、禁用 |
| 语义-成功 | `#10B981` | 完成、合格、启用 |
| 语义-警告 | `#F59E0B` | 待处理、临期 |
| 语义-危险 | `#EF4444` | 缺货、不合格、删除 |
| 语义-信息 | `#64748B` | 中性状态 |
| 强调-仓储橙 | 渐变 `#EA8A00→#FBBF24` | 仅用于 KPI 图标与数据大屏点缀 |
| 工作区背景 | `#F3F5FA` | 内容区 |
| 卡片 | `#FFFFFF` + 边框 `#E9EDF5` + 轻阴影 | 所有容器 |
| 侧边栏 | 渐变 `#0D1B39→#12275A`（夜航蓝） | 品牌承载区 |

## 三、布局与组件规范

### 1. 页面骨架（列表页）
```
┌─ 搜索卡片 ─────────────────────────────┐
│  标签 输入 ▾  标签 输入   [搜索] [重置]  │
└───────────────────────────────────────┘
┌─ 表格卡片 ─────────────────────────────┐
│ ▎表格标题            [主操作] ⟳ ⚙ ⛶   │  ← 标题左侧 4px 品牌蓝竖条
│ ┌─────────────────────────────────────┐│
│ │ 表头 #F6F8FC · 字重600 · #475569     ││
│ │ 行 hover #F2F6FF · 边框 #EEF1F7      ││
│ │ 状态列：胶囊标签+圆点                  ││
│ └─────────────────────────────────────┘│
│                        共 N 条 ‹ 1 2 › │
└───────────────────────────────────────┘
```

### 2. 侧边栏（夜航蓝）
- 菜单项：高 44px、左右缩进 10px、圆角 8px、文字 `rgba(255,255,255,.62)`；
- 激活项：品牌蓝渐变胶囊（`90deg, #2563EB 90% → #4D8BFF 62%`）+ 投影 + 白字；
- 悬停：`rgba(91,132,240,.18)`；
- Logo 区：深蓝 `#0C1834`，标题"智联仓储 WMS"字重 700、字距 1px。

### 3. 状态标签（全局自动生效）
- 胶囊形（圆角 999px）、无边框、浅底色字；
- 表格/描述/弹窗内的 light 标签自动带 5px 语义圆点；
- 业务枚举颜色由 `src/constants/wms.ts` 的 `tag` 字段统一控制，页面不得自定状态色。

### 4. KPI 统计卡（工作台/看板专用）
```html
<div class="wms-kpi-card bg-white p-4">
  <div class="wms-kpi-title">今日入库单</div>
  <div class="wms-kpi-value">85 <span class="wms-kpi-unit">单</span></div>
  <div class="wms-kpi-icon blue"><!-- el-icon --></div>  <!-- blue|green|orange|red -->
</div>
```
- 数值 26px/700 + 单位 12px 灰；环比 ↑绿 ↓红 + "较昨日"；
- 图标底座 48px 圆角 12px 渐变（四色可选）；
- hover 上浮 2px + 阴影加深。

### 5. 弹窗/抽屉
- 圆角 14px、双层柔和阴影、标题 600 字重；
- 表单控件圆角统一 6px（`--el-border-radius-base`）。

## 四、页面分类与既定模式

| 页面类型 | 数量 | 模式 |
|---|---|---|
| 登录页 | 1 | 左品牌展示区（大标题+特性+迷你看板）+ 右登录卡（记住我/协议/渐变按钮），点阵背景 |
| 工作台/看板 | 3 | KPI 卡行 + 快捷操作 + 图表卡（参考 `views/welcome`） |
| 列表查询/CRUD | ~44 | 一屏两卡骨架（自动继承，无需额外代码） |
| 树形/主从 | 3 | el-card 左右或树形表格（menu/org/dict） |
| 数据大屏 | 1 | 深色主题（独立设计，不受本规范 light 变量影响） |

## 五、表格列宽规则（强制）

- 非固定列一律使用 `minWidth`（下限），**禁止** `width` 固定值——el-table 自动将剩余宽度分配给 minWidth 列，保证表格始终铺满容器 100%、无右侧空白与横向溢出；
- 仅 `fixed: "right"` 的操作列允许 `width`；
- minWidth 基准值：日期 140、单号 130、名称 120、编码/状态 100、数量 80；
- 内容超宽由 `show-overflow-tooltip` 兜底，详情抽屉展示全量字段。

## 六、组件级规范（全局皮肤自动生效）

| 组件 | 规范 |
|---|---|
| 主按钮 | 品牌蓝渐变（135deg #2563EB→#3B76F2）+ 投影，active 下沉 1px |
| 次按钮 | 描边 #D8DFEA，hover 蓝字淡蓝底 |
| 输入/选择器 | 圆角 8px、1px 内描边，hover 加深、focus 品牌蓝 1.5px |
| 表格 | 行高 ~46px（cell padding 11px）、表头 46px 高 #F6F8FC、border 模式整体 10px 圆角裁切 |
| 分页 | 圆角 8px，激活页品牌蓝渐变胶囊 |
| 状态标签 | 胶囊 + 语义圆点（表格/描述/弹窗内自动） |
| 详情描述 | el-descriptions 标签底 #F6F8FC、字重 600、整体圆角 |
| 对话框按钮 | 最小宽 84px |
| 进度条/时间线 | 胶囊圆角 / 节点光环 |

## 七、约束

1. **禁止**页面内写死状态颜色，一律走 `constants/wms.ts` 字典；
2. **禁止**修改 `wms-theme.scss` 中的设计令牌值来适配单页需求；
3. **禁止**表格列使用 `width` 固定宽（操作列除外）；
4. 新增页面只需按 CONVENTIONS.md 的三件套结构开发，皮肤自动生效；
5. 图标统一 `~icons/ep/xxx`；数字展示务必保留 `tabular-nums`（已全局注入）。

## 八、暗色模式

暗色模式（`html.dark`）不受本皮肤影响，保持 pure-admin 原生暗色。如需品牌化暗色，在 `wms-theme.scss` 追加 `html.dark` 作用域块。
