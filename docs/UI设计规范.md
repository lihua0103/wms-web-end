# 智联仓储 WMS · UI 设计规范

> 设计语言：**深海藏青 × 远航青 × 国际橙** —— 国际物流平台定位，大胆用色、数据密集、品牌感强。
> 参考对象：Flexport（国际物流 SaaS）、Dify/LobeChat（开源智能体平台）。
> 实现层：`src/style/wms-theme.scss`（全局皮肤，自动作用于所有页面）+ 页面级组件类。
> **颜色一律走 pure-admin 主题变量**（见第九节），禁止硬编码色值。
> 新页面**无需额外样式代码**即自动继承本规范；如需定制，只用本文档定义的类与变量。

## 一、设计原则

1. **一屏两卡**：每个列表页 = 搜索卡片 + 表格卡片，圆角 12px、中性冷灰背景上浮起；
2. **状态即语义**：所有业务状态用"胶囊标签 + 语义圆点"呈现，一眼读出单据状态；
3. **数字可读**：所有数量/单号使用等宽数字（tabular-nums），对齐不跳动；
4. **石墨导航、浅色工作区**：侧边栏承载品牌（石墨夜航深色），内容区保持冷静克制。

## 三、布局与组件规范

### 1. 页面骨架（列表页）
```
┌─ 搜索卡片 ─────────────────────────────┐
│  标签 输入 ▾  标签 输入   [搜索] [重置]  │
└───────────────────────────────────────┘
┌─ 表格卡片 ─────────────────────────────┐
│ ▎表格标题            [主操作] ⟳ ⚙ ⛶   │  ← 标题左侧 4px 品牌蓝竖条
│ ┌─────────────────────────────────────┐│
│ │ 表头 #F5F7FA · 字重600 · #475569     ││
│ │ 行 hover #F2F8FA · 边框 #ECF0F4      ││
│ │ 状态列：胶囊标签+圆点                  ││
│ └─────────────────────────────────────┘│
│                        共 N 条 ‹ 1 2 › │
└───────────────────────────────────────┘
```

### 2. 侧边栏（深海藏青，大型企业平台标准形态）
- Logo 区：Logo + 系统名单行，不加副标题/切换器等非标元素；
- 菜单项：顶层 44px、子级 40px、缩进 8px、圆角 6px、文字 `rgba(203,222,241,.74)`；
- **激活项：主色实底条 + 白字（Ant Design Pro 同款范式），不加投影/灯条/渐变**；
- 含选中项或展开中的父级：仅文字点亮白 + 强调色箭头，不加底色；
- 悬停：`rgb(255,255,255,.07)` 浮层 + 文字提亮；
- 菜单排序：基础数据（主数据/库存）→ 业务作业（入库/出库/库内）→ 结算协同（运输/计费）→ 数据集成（报表/设备）→ 系统管理沉底；
- Logo 区 `#1C3459` + 发丝分隔线；品牌差异由配色体系（藏青底 + 远航青主色）承载，不做装饰性发明。

### 3. 状态标签（全局自动生效）
- 胶囊形（圆角 999px）、无边框、浅底色字；
- 表格/描述/弹窗内的 light 标签自动带 5px 语义圆点；
- 业务枚举颜色由 `src/constants/wms.ts` 的 `tag` 字段统一控制，页面不得自定状态色。

### 4. KPI 统计卡（工作台/看板专用）
```html
<div class="wms-kpi-card bg-white p-4">
  <div class="wms-kpi-title">今日入库单</div>
  <div class="wms-kpi-value">85 <span class="wms-kpi-unit">单</span></div>
  <div class="wms-kpi-icon blue"><!-- el-icon --></div>  <!-- blue|green|orange|red -->
</div>
```
- 数值 26px/700 + 单位 12px 灰；环比 ↑绿 ↓红 + "较昨日"；
- 图标底座 48px 圆角 12px 渐变（四色可选）；
- hover 上浮 2px + 阴影加深。

### 5. 弹窗/抽屉
- 圆角 14px、双层柔和阴影、标题 600 字重；
- 表单控件圆角统一 6px（`--el-border-radius-base`）。

## 四、页面分类与既定模式

| 页面类型 | 数量 | 模式 |
|---|---|---|
| 登录页 | 1 | 左品牌展示区（大标题+特性+迷你看板）+ 右登录卡（记住我/协议/渐变按钮），点阵背景 |
| 工作台/看板 | 3 | KPI 卡行 + 快捷操作 + 图表卡（参考 `views/welcome`） |
| 列表查询/CRUD | ~44 | 一屏两卡骨架（自动继承，无需额外代码） |
| 树形/主从 | 3 | el-card 左右或树形表格（menu/org/dict） |
| 数据大屏 | 1 | 深色主题（独立设计，不受本规范 light 变量影响） |

## 五、表格列宽规则（强制）

- 非固定列一律使用 `minWidth`（下限），**禁止** `width` 固定值——el-table 自动将剩余宽度分配给 minWidth 列，保证表格始终铺满容器 100%、无右侧空白与横向溢出；
- 仅 `fixed: "right"` 的操作列允许 `width`；
- minWidth 基准值：日期 140、单号 130、名称 120、编码/状态 100、数量 80；
- 内容超宽由 `show-overflow-tooltip` 兜底，详情抽屉展示全量字段。

## 六、组件级规范（全局皮肤自动生效）

| 组件 | 规范 |
|---|---|
| 主按钮 | 品牌青渐变（135deg #0E7490→#1289A8）+ 投影，active 下沉 1px |
| 次按钮 | 描边 #D6DDE8，hover 青字淡青底（#F2FAFC） |
| 输入/选择器 | 圆角 8px、1px 内描边，hover 加深、focus 品牌青 1.5px |
| 表格 | 行高 ~46px（cell padding 11px）、表头 46px 高 #F5F7FA、border 模式整体 10px 圆角裁切 |
| 分页 | 圆角 8px，激活页品牌青渐变胶囊 |
| 状态标签 | 胶囊 + 语义圆点（表格/描述/弹窗内自动） |
| 详情描述 | el-descriptions 标签底 #F6F8FC、字重 600、整体圆角 |
| 对话框按钮 | 最小宽 84px |
| 进度条/时间线 | 胶囊圆角 / 节点光环 |

## 七、约束

1. **禁止**页面内写死状态颜色，一律走 `constants/wms.ts` 字典；
2. **禁止**修改 `wms-theme.scss` 中的设计令牌值来适配单页需求；
3. **禁止**在组件样式里硬编码品牌色/强调色（如 `#0e7490`），一律用 `var(--el-color-primary*)` 与 `var(--pure-theme-*)`（见第九节）；
4. **禁止**表格列使用 `width` 固定宽（操作列除外）；
5. 新增页面只需按 CONVENTIONS.md 的三件套结构开发，皮肤自动生效；
6. 图标统一 `~icons/ep/xxx`；数字展示务必保留 `tabular-nums`（已全局注入）。

## 八、暗色模式

暗色模式（`html.dark`）不受本皮肤影响，保持 pure-admin 原生暗色。如需品牌化暗色，在 `wms-theme.scss` 追加 `html.dark` 作用域块。

## 九、主题色机制（必须遵守）

所有品牌色/主题色**接入 pure-admin 既有机制**，由设置面板统一驱动，不得另起一套：

| 场景 | 使用的变量 | 说明 |
|---|---|---|
| 按钮、链接、分页、输入框 focus、标签页激活、表格 hover、侧栏激活胶囊 | `--el-color-primary` + `light-3/5/7/8/9`、`dark-2` | 由 `useDataThemeChange().setEpThemeColor()` 运行时写入，用户在设置面板切换主色时全部联动 |
| 侧栏底色、Logo 区、菜单文字、悬停底色 | `--pure-theme-menu-bg`、`--pure-theme-sidebar-logo`、`--pure-theme-menu-text`、`--pure-theme-menu-hover`、`--pure-theme-sub-menu-*` | 由 `theme.scss` 按 `html[data-theme]` 提供；本皮肤仅在 `html[data-theme="default"]` 定制"深海藏青"色板 |
| 侧栏折叠指示条、父级箭头高亮 | `--pure-theme-menu-active-before` | 各主题自带强调色 |
| 半透明派生色（阴影、淡底、光晕） | `color-mix(in srgb, var(--…) N%, transparent/#fff)` | 保证任意主题下派生色都跟随主色，不写死 rgba |

默认主题（`default`）对应设置面板主题色板的第 2 个色块，色块色值即品牌主色 `#0E7490`（见 `useDataThemeChange.ts` 的 `themeColors`），做到所见即所得。

## 十、智能体（WMS 智能体）

参考 Dify / LobeChat 的智能体交互范式，实现在 `src/layout/components/lay-ai/index.vue`：

- **顶栏入口**：品牌渐变胶囊（跟随 `--el-color-primary`）+ 在线状态圆点，位于顶栏右侧首位；
- **侧滑对话面板**（420px 抽屉）：渐变头部（头像/名称/在线状态）、欢迎语、2×2 技能卡（查库存/追单据/找异常/出报表，点击即发送指令）、底部圆角输入框 + 发送按钮；
- 消息气泡：助手白色（左）、用户主色渐变（右），对话开始后技能卡自动收起；
- 当前为预览模式（占位回复）；后端智能体就绪后，在组件内 `send()` 处接入会话 API 与工作流编排即可，界面无需改动。
